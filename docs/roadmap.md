# 到達目標ロードマップ（入茶 → 入緑）

AtCoder で茶色（rating 400–799）・緑色（rating 800–1199）に到達するために必要な
アルゴリズムと精進計画。チェックボックスを進捗の指標として使う。

- 最終更新: 2026-09-10
- 対応タグ語彙: [TAGS.md](../TAGS.md) ／ 入力の書き方: [proconio-cheatsheet.md](proconio-cheatsheet.md)

## 現在地（2026-09-10 時点）

| 項目 | 進捗 |
| --- | --- |
| 鉄則本 | A02–A15（1〜3 章: 計算量 / 累積和 / 二分探索）、B02–B14 |
| 競プロ典型 90 問 | 001–004, 007 |
| `library/` スニペット | `bfs` / `dfs` / `binary_search` |
| ABC | abc284, abc325, abc471–473 の一部 |

**最大の穴: 鉄則本 4 章以降（DP・数学・データ構造・グラフ）が丸ごと未着手。**
入茶に足りないものと入緑に足りないものはほぼ同じで、どちらもここに集中している。

## レート帯の定義

| 色 | rating | 必要な perf | ABC での目標 |
| --- | --- | --- | --- |
| 茶 | 400–799 | 800 前後 | A/B/C の 3 完を安定させる |
| 緑 | 800–1199 | 1200 前後 | 3 完を高速化 + D を 50% 以上通す |

- 初期補正が 400 なので、茶色ラインに乗せるには perf 800 程度が数回必要
- ABC で A/B/C のみ正解した場合の perf はおおむね 400〜700
- 緑は全参加者の上位 20% 程度。ABC-D の diff はおおむね 600〜1100
- **参加回数と rating には強い相関がある（5 回参加で中央値 241、10 回で 521）。**
  過去問より参加数が効く帯なので、まず毎週出ること

# STEP 2: 入緑（rating 800）

茶色が「知識ゼロでも全探索で押し切れる」帯だったのに対し、緑は
**名前のついたアルゴリズムを持っていないと解けない問題**が明確に増える。

ただし複数の入緑記事に共通するのは「ダイクストラやワーシャルフロイドは
結局ほとんど使わなかった」という証言。**DP と考察テクニックへの投資対効果が突出して高い。**

## Rust 固有の要点

### ac-library-rs が使える

`compete.toml` のテンプレート依存に **`ac-library-rs = "=0.2.0"` が既に入っている**。
`Dsu` / `FenwickTree` / `Segtree` / `ModInt998244353` / `SccGraph` を自前実装せずに使えるので、
Union-Find・セグ木・BIT・modint は**ライブラリ整備の手間がほぼゼロ**。まずここを使えるようにするのが最短。

### 言語要因の WA / TLE

| 罠 | 対策 |
| --- | --- |
| `usize` の減算アンダーフロー（グリッド探索で頻発） | `checked_sub` か `i64` で座標計算してから `as usize` |
| `i32` オーバーフロー | 素直に `i64` / `u64` |
| `lower_bound` が無い | `partition_point`（`binary_search` は等値がないと `Err`） |
| `f64` のソート | `sort_by(|a, b| a.partial_cmp(b).unwrap())` |
| `BinaryHeap` は最大ヒープ | `std::cmp::Reverse` で最小ヒープ化（ダイクストラ必須） |
| DP の INF でオーバーフロー | `i64::MAX / 2` を使う（`MAX` だと加算で panic / wrap） |
| `HashMap` のデフォルトハッシャが遅い | 10^6 規模なら `BTreeMap` か FxHash 相当に置換 |
| 再帰 DFS のスタック溢れ | 深さ 10^5 超は非再帰化、または `std::thread::Builder::stack_size` |
| `usize` アンダーフロー（木・グラフの親管理） | `Option<usize>` か番兵 `usize::MAX` |
| 大量出力の TLE | `#[proconio::fastout]`（テンプレートで対応済み） |

## 精進プラン

入茶と入緑で別のことをやる必要はない。**鉄則本を最後まで進めれば上表はほぼ全部カバーされる。**

1. **鉄則本 A16–A25（4 章 DP）** — 最優先。C の DP 枠が取れるようになる
2. **鉄則本 A26–A31（5 章 数学）** — 素数・約数・mod・nCr の典型が入る
3. **鉄則本 A32–A45（6 章 考察テクニック）** — 緑の ★★★ が集中している章
4. **鉄則本 A50–A69（8〜9 章 データ構造・グラフ）** — Union-Find・ダイクストラ・優先度付きキュー
5. **競プロ典型 90 問の ★2〜★4** — 008 以降。★4 までが緑〜水の考察トレーニングとして最適
6. **ABC の D 埋め（diff 600〜1100）** — AtCoder Problems の Difficulty 順に低い方から
7. **毎週 ABC に出る** — 過去問より参加数が rating に効く

> 6 を先にやりたくなるが、DP の型がない状態で D を埋めても解説を読むだけになる。
> **1〜2 を終えてから 6 に入る**のが効率的。

### `library/` に追加する順番

1. [ ] 順列全探索
2. [ ] Union-Find（or `ac_library::Dsu` を使う）
3. [ ] ダイクストラ
4. [ ] nCr 前計算（mod 逆元）
5. [ ] 座標圧縮
6. [ ] 累積和・いもす法
7. [ ] 素数判定・約数列挙・エラトステネスの篩
