# hint

未 AC の問題に段階的にヒントを出す。**答えを先に言わないことが唯一の価値**。

## 必ず守ること

**解答ファイル（`*/src/bin/*.rs`）を読まない。** 読んでよいのは問題文（Web）、`TAGS.md`、`docs/`、`README.md` だけ。

- ユーザーの書きかけを読むと、ヒントがそのコードの添削に化ける
- 他の問題の AC コードを読むと、解法を知った状態で「ヒント」を書くことになる
- 例外は 2 つだけ: ユーザーがコードを会話に貼った / 「自分の方針は合ってる?」と明示的に聞いた

**ファイルに書き込まない。テストも実行しない。** 写経と検証はユーザーの仕事。

## 問題の特定

| 言われ方 | 組み立てる URL |
| --- | --- |
| `abc255 b` / `abc255_b` | `https://atcoder.jp/contests/abc255/tasks/abc255_b` |
| `tasks/` を含む URL | `tasks/` の後ろが正規 ID。バーチャル（`adt_*` など）でも本コンテストの URL に直す |
| `typical90 018` など形式が特殊なもの | 推測で組み立てず、URL を聞く |

WebFetch で**必ず実物の制約を取る**。取得に失敗したら記憶で補わず、問題文を貼ってもらう。制約を取り違えたヒントは嘘になる。

## 段階 1（既定）— この 4 つを、この順で、これだけ

1. **確認した制約** — N の上限、値の範囲、許容誤差。WebFetch で取った実物
2. **言い換え** — 何を求める問題かを 1〜2 文の平易な日本語で。解法名は使わない
3. **着眼点** — 注目すべき構造を**問いの形**で 1〜3 個（例:「各人が必要とする明るさは何で決まる?」）
4. **計算量の目標** — 制約からの逆算を 1 文で（例:「N ≤ 1000 なので O(N²) までは通る」）

締めに 1 行: 「ここまでで方針は立ちそう? 詰まったら『もっと』と言ってください。」

解法の式・型・精度・コードは段階 1 の持ち物ではない。それぞれ段階 2 と 3 に置き場所がある。

## 段階 2 —「わからない」「もっと」、またはユーザーが自分の方針を述べたとき

1. **方針が述べられていたら、まず正誤を判定する。** 誤りなら**最小の反例**を数値で構成し、期待値と実際の値を並べて表で示す。「違います」だけで終わらせない
2. 小さい入力で手を動かした具体例・表・図
3. 計算量の詰め、型とオーバーフロー、精度（二乗のまま比較して `sqrt` は最後に 1 回、など）
4. 落とし穴
5. 解法の当たり外れ（「この問題に二分探索は要らない」「ここは貪欲では詰む」など、特定の解法の要否）

## 段階 3 —「模範コード」「写経したい」「コードちょうだい」

チャットに表示するだけ。ファイルには書かない。

- 1 行目に `// algo: <TAGS.md の語彙>`。語彙に無いタグなら TAGS.md への追記も促す
- `compete.toml` の template の `use` 文をそのまま使う
- main の前に考察コメント（計算量の根拠、型の理由、落とし穴）
- main の後ろに `// alt:` ブロック。1 行目に**何がどう良いか**を必ず書く
- ジャッジ環境: Rust 1.89 / edition 2024 / proconio 0.5.0

`/hint abc255 b コードまで` のように最初から深さを指定されたら段階を飛ばしてよい。

## Red flags — 手を止める

- `src/bin/` を開こうとしている
- 段階 1 に `答え = max_i min_j ...` のような**解法の式**を書いている
- 段階 1 で型・オーバーフロー・出力精度に触れている
- 制約を確認せずに書き始めている
- 締めの 1 行を書かずに終えようとしている

| 言い訳 | 現実 |
| --- | --- |
| 「既存コードを見た方が的確なヒントが出せる」 | それは添削。ヒントは問題文だけから書く |
| 「制約は覚えている」 | 覚え違いが 1 つあればヒント全体が嘘になる。WebFetch する |
| 「一度に全部出した方が親切」 | 自分で気づく機会を奪うのが最大の損失。段階 1 で止まる |
| 「この問題は簡単だから段階を分ける意味がない」 | 簡単かどうかを決めるのはユーザー |

## AC したら

`annotate` skill で `// algo:` と `// alt:` を付ける。
